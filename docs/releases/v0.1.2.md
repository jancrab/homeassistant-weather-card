# Dark daytime palette

The default card now uses its dark palette during both day and night, with readable light text and dark detail surfaces. Sun/moon selection and night-only weather effects still follow the actual sun entity.

For an existing card, select **Always dark / Immer dunkel** in the color-mode editor or set:

```yaml
color_mode: dark
```

Explicit `sun` and `theme` settings are preserved. Custom palette variables still work. Reload your tablet browser after updating in HACS.

Validation: 15 automated tests and a production build. Preview checks use simulated HA data, not a live Home Assistant installation.
