# Tablet layout and collapsing fixes

- Remove the visible five-hour heading; the details control stays on the right.
- Disabling all three outlook features removes the complete section. Cards without an explicit height no longer fall back to 200 px.
- Enable **Compact tablet layout** in the editor or add `compact: true` to existing cards. Horizontal value rows wrap, spacing shrinks and normal flow layouts fit their content. New starter cards enable this by default; saved layout choices are preserved when turning it off.
- Freely positioned Home/Arc scenes reserve their own space above the outlook.
- The UV editor now explains when the chosen source has no current UV value. The setup guide covers automatic use of the weather entity's `uv_index` attribute and optional OpenUV sensors.

Use `grid_options.rows: auto` in Sections dashboards so the dashboard can shrink with the card. Reload the tablet browser after updating in HACS.

Validation: 14 automated tests and a production build; browser checks use simulated HA data. This has not been verified in a live Home Assistant installation.
