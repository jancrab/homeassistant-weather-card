# Matching glass panels

The hourly forecast and precipitation panels now use the same translucent glass appearance as Slim's upper weather values: fine borders, rounded corners, backdrop blur and the existing shadow tokens.

The original weather scene remains animated. Details still expand and collapse smoothly; the hourly HA icons are static. Reduced-motion settings continue to be respected.

Validation: 15 automated tests and the production build. Visual checks use simulated HA data, not a live installation.
