# Direct touch without the details toolbar

The separate details toolbar is gone. Tap the hourly forecast to smoothly expand or collapse precipitation and UV. The same touch target supports Enter/Space and exposes its expanded state to screen readers.

When the hourly overview is disabled or unavailable, enabled details appear directly. `details_mode: always` still keeps them open. If there are no collapsible details, tapping the forecast opens the weather entity.

15 automated tests and a production build; browser checks use simulated HA data.
