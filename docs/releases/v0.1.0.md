First independent release of Home Assistant Weather Card, based on Origami Weather by hazymorning (GPL-3.0). Original Git history, layouts, animation assets and attribution are preserved.

## Features

- Animated current weather and a compact five-hour forecast.
- Tap **Details** to smoothly expand hourly precipitation, the five-hour total and optional current UV. The overview remains visible; live updates preserve your choice.
- Visual editor switches for hourly forecast, precipitation, UV and always-visible details.
- Optional UV sensor, German/English labels, HA time zone and entity units, explicit missing-data states.
- One self-contained JS bundle; no runtime CDN dependency.
- Tablet setup guide and reusable visual-design guide.

## Install

Add **https://github.com/jancrab/homeassistant-weather-card** to HACS custom repositories as **Dashboard**, download the card and reload your browser. Resource: `/hacsfiles/homeassistant-weather-card/homeassistant-weather-card.js` (JavaScript module).

```yaml
type: custom:homeassistant-weather-card
weather_entity: weather.home
show_hourly: true
show_precipitation: true
show_uv: true
details_mode: toggle
```

Replace `weather.home` with your weather entity. It must support hourly forecasts. Set `details_mode: always` to keep details open. For manual installation, copy the attached JS file to `config/www/` and register `/local/homeassistant-weather-card.js` as a JavaScript module.

See [tablet setup](https://github.com/jancrab/homeassistant-weather-card/blob/main/docs/tablet-setup.md) for a ready-to-paste configuration and lighter animation settings.

## Verification and limitations

12 local tests and the production build pass. Simulated browser checks cover light/dark themes, narrow layouts, missing data, errors, touch/click and keyboard disclosure. Actual Home Assistant installation and provider-specific behavior have not yet been verified on a real dashboard. Precipitation is hourly, not minute-by-minute rain radar; UV depends on the chosen entity or sensor.
